처음에는 카테고리 별로 폴더를 만들어서 글을 나눠놨는데, 뭘 적는지도 잘 모르겠고
분류하기 애매한 것들도 많아져서 지금은 아래와 같은 구조로 나눴다.

## 분류

-  inbox
임시 보관소, 일단 대충 적은건 다 여기

- notes
내 생각이 정리된 폴더
**내가 재구성한 내용을 작성**

- reference
책이나 공식문서 같은 외부에서 온 정보를 보관하는 곳
**최대한 사실에 대해서만 작성**

비슷한 글 많음, 정리 기깔난 곳 많음 -> reference
딱봐도 내가 쓴 글임 -> notes


## 링크와 태그
기존에 가지고 있던 계층은 링크로 표현한다
```
DirectX
├─ Framebuffer
├─ Deferred Rendering
```

계층을 태그로 표현하지 않는다.
태그를 다는건 나중에 모아보기 위함이니까 성격이나 상태들에 주로 사용한다.
